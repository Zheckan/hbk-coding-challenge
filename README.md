# Weather Alerts Explorer

A React and TypeScript application for finding and reading National Weather
Service alerts.

## Local development

Use Node.js 24 or newer and pnpm 10.

```bash
pnpm install
pnpm dev
```

The development server prints its local URL after startup.

## Checks

```bash
pnpm check
```

This runs formatting checks, type-aware linting, TypeScript, and the production
build. Automated behavior tests will be added with the first application
feature.
